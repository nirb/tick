# Project: Family Task PWA (Cloudflare Stack)

You are the lead full-stack engineer building this app.

## Core Rules:
1. Always use TypeScript for Worker code and React.
2. Store relational data strictly in Cloudflare D1 using parameterized SQL.
3. For Web Push, use WebCrypto-compatible libraries (e.g., `@pushforge/builder` or Node-compat Web Push).
4. Follow the architecture defined in `srs.md`.
5. Never deploy the client (`npm run deploy`, `wrangler pages deploy`, etc.) unless explicitly instructed by the user.
